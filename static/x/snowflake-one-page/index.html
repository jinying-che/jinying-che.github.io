Snowflake

企业用它把分散的数据变成可用的分析与 AI

Snowflake 是一家面向企业的云数据平台公司。数据工程团队用它整理数据，分析师用 SQL 做报表，开发者在同一套权限规则下构建 AI 应用。Snowflake 运行在 AWS、Azure 和 Google Cloud 的基础设施上。11

它卖什么

核心是托管数据仓库。存储保存数据，独立计算集群处理查询。报表和批处理可以各自扩容，数据继续共用。11

它怎么收费

按计算、存储和适用的数据传输用量收费。更多查询、数据管道或 AI 任务可能拉动消耗。优化查询也能减少完成同一任务所需的计算量。112

Snowflake

A cloud platform for turning scattered data into analytics and AI

Snowflake sells a managed cloud data platform to enterprises. Data engineers organize data, analysts run SQL reports, and developers build AI applications under the same access policies. The platform runs on AWS, Azure, and Google Cloud.11

What Snowflake sells

The core product is a managed data warehouse. Storage holds the data and independent compute clusters run queries. Reporting and batch jobs can scale separately while using the same data.11

How Snowflake gets paid

Customers pay for compute, storage, and applicable data transfers. More queries, pipelines, or AI jobs can raise usage. More efficient queries can lower consumption for the same work.112

Workflows create switching costs

Pipelines, reports, and access rules take work to move and validate. Secure sharing gives other accounts query access to selected data. Open formats such as Iceberg let other engines use the same data, lowering some switching costs.21318
